#Signal Post Week 1 | Cost Literacy | AI costs in creative agencies

##Hook - Why should anyone care about AI costs in your beat?:
Especially in creative processes nowadays, it is necessary to use AI to keep up with competitors. The goal is to work faster and create even better outcomes. However, the use of AI comes with costs, so it is really important to identify the costs, make them visible to the client, and include them in cost estimates/offers so that the output stays lucrative. This is especially important because, with the development of AI, it is becoming and will become easier to justify the use of AI tokens than actual working hours

##The Numbers - Describe a specific AI use case in your beat. Estimate the token volume. Calculate monthly cost using real provider pricing. Show your work.
Use case: Writing social media posts
Writing social media posts is also part of the business of creative agencies. Whether it’s a post for Instagram or LinkedIn, AI can help create and improve texts and take them to the next level.I therefore researched how many input and output tokens are used on average for a social media post written with Claude Sonnet. Further I looked up what the tokens actually cost. I found a really good overview on the Langdock website, which provides a realistic view of the costs. Using this, I was able to calculate the actual monthly cost for 50 posts.

- Input token/ Post = 150
- Output Token/ Post = 250
- Posts/ month = 50
- Total input tokens/month = 150 × 50 = 7,500
- Total output tokens/month = 250 × 50 = 12,500

- Costs for Sonnet 5 via Langdock
- Input Tokens: €1.75 / 1M tokens -> $1.90/ 1M tokens
- Output Tokens: €8.73 / 1M tokens -> $9,49/ 1M tokens
- Input Tokens: $0.00190 / 1,000 tokens
- Output Tokens: $0.00949 / 1,000 tokens

- For ($0.00190 /1K input, $0.00949 /1K output):
- Input cost = (7,500 / 1,000) × $0.00190   = 0.01425$
- Output cost = (12,500 / 1,000) × $0.00949  = 0.118625$
- Token cost/month = Input cost + Output cost = 0.132875$

##The Insight - What surprised you? What’s the takeaway?
I was surprised by the fact that writing these 50 posts isn’t really expensive. I would have thought it would cost more. This shows me that whether I need to pay close attention to token usage probably depends on the task I’m doing. 
For example, when I completed all those Week 1 assignments with the help of AI, I almost reached my user limit. The associated costs may be much higher for tasks like this, because a lot more input and output tokens were used when I asked Langdock to explain the steps for setting up GitHub.If I apply this to the creative agency, other work, for example, creating entire pitches and presentations or creating new brand assets, is probably much more sensitive to rising costs than simply writing an Instagram post.
